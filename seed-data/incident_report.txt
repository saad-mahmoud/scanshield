SECURITY INCIDENT REPORT #IR-2025-003
Classification: Medium
Date detected: 2025-01-28 14:22 UTC
Date resolved: 2025-01-28 18:45 UTC
Reported by: Alex Kim, Security Engineer (a.kim@acmecorp.com)

SUMMARY:
A misconfigured S3 bucket (s3://acme-client-exports-prod) was publicly accessible for approximately 6 hours between 08:00 and 14:22 UTC on January 28. The bucket contained CSV exports with client data.

AFFECTED DATA:
The following export files were in the bucket:
- meridian_health_employees_jan2025.csv (2,341 records)
- novatech_scan_results_dec2024.csv (891 records)
- truenorth_risk_assessment.csv (156 records)

Sample of exposed data fields per record:
- Full name, email address, job title
- IP addresses from network scans
- In the Meridian file: SSNs were included by mistake (e.g., 419-55-7231, 528-44-7193, 331-82-6654, 672-41-8903)
- In the NovaTech file: internal hostnames and MAC addresses (e.g., 00:1A:2B:3C:4D:5E, 00:1A:2B:3C:4D:6F)

ROOT CAUSE:
During deployment of the new export feature (PR #1247, merged by David Park), the bucket policy was overwritten with a public-read ACL. The Terraform state file had a conflict that wasn't caught in code review.
